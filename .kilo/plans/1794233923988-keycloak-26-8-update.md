Relevante Facts, die die Planung tragen:

- KC `26.8.2` ist die aktuelle Patch-Stufe (`keycloak-core` 26.8.0/.1/.2 auf Maven Central), `@keycloak/keycloak-admin-client` `latest` = `26.8.2`.
- SPI-gegenprüfung direkt am 26.8.2-Quellstand:
  - `org.keycloak.utils.RoleResolveUtil#getResolvedRealmRoles(KeycloakSession, ClientSessionCtx, boolean)` existiert mit identischer Signatur (`services/.../utils/RoleResolveUtil.java`). **Achtung:** sie liefert nur Rollen über `clientSessionCtx.getRolesStream()`, also scope-mapping-abhängig → `fullScopeAllowed` am Client `ballwareweb` darf nicht angefasst werden.
  - `org.keycloak.services.cors.Cors` (Modul `server-spi-private`) stellt weiterhin `builder()`, `auth()`, `allowAllOrigins()`, `add(ResponseBuilder)`, `AUTHORIZATION_HEADER` bereit; `DefaultCors.java` ist zwischen 26.6.3 und 26.8.2 bitidentisch.
  - grep über `token-mapper/src` und `user-role-api/src`: keine Treffer für `getTransactionManager`, `AsyncResponse`, `HttpResponse`, `ContextNotActiveException` → die neuen Transaktionsregeln (26.7.0) betreffen den Code nicht.
- `realm.getRole("ballware-admin")` (`RoleRestProvider`) hat keinen Treffer im Import-JSON: die Rolle existiert nur in einer laufenden Umgebung. Für Tests gezielt anlegen oder die vorhandene Realm-Role `"Globaler Tenant Administrator"` (`import/ballware-realm.json:82`) verwenden.

## 2. Festgelegte Entscheidungen

1. **Pin 26.8.2 überall** (Image, beide POMs, admin-client) – Compile-Basis = Laufzeit-Basis.
2. **`import/ballware-realm.json` wird aus 26.8.2 neu erzeugt** (Import des alten JSON → 26.8.2-normalisieren → Export) und das ballware-Delta wird danach geprüft/wiederhergestellt.
3. **Dev-Container auf PostgreSQL umgestellt** (KC 26.8 unterstützt SQL Server 2019/2022 bzw. Azure SQL „latest“; `azure-sql-edge` ist abgekündigt, Dev = Prod).
4. **Prod: nur DB-Migration + Verifikation, kein Re-Import** des Realms (`--import-realm` überspringt ein vorhandenes Realm; die Migration ergänzt `kc-admin-api` und die Policies automatisch).

3. **Custom REST-Endpunkte** (`/realms/ballware/ballware-role-api`, `/realms/ballware/ballware-user-api`):
